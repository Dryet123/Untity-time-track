# Unity Time Tracker

Трекер времени в Unity для Windows (WPF, .NET 10, SQLite).

- Сам находит запущенные редакторы Unity: проект берёт из `-projectPath`, сцену из заголовка окна.
- Считает время, пока Unity открыт, и время, пока окно Unity активно и есть ввод с клавиатуры или мыши. Отдельно идёт время в Rider, Visual Studio, VS Code и Cursor, если в заголовке окна есть имя проекта.
- Вкладки: Overview (метрики и графики за день/неделю/месяц/год/всё время), Calendar (тепловая карта года, месяц, таймлайн дня), Projects (информация о проекте, своя иконка, цвет, статистика по проекту), Log (сессии, экспорт в CSV), Settings.
- Список проектов подтягивается из Unity Hub.
- Крестик сворачивает в трей, выход через меню трея.
- Автозапуск через запись `Run` в реестре. Она видна в диспетчере задач на вкладке «Автозагрузка», включается и выключается там или в Settings.

## Установка

```powershell
.\publish.ps1
```

Собирает Release в `%LOCALAPPDATA%\Programs\UnityTimeTracker` и запускает. При первом запуске Release-сборка сама регистрирует автозапуск.

Данные лежат в `%LOCALAPPDATA%\UnityTimeTracker` (`tracker.db`, `settings.json`, `icons\`). Для тестов папку можно подменить переменной окружения `UTT_DATA_DIR`.
